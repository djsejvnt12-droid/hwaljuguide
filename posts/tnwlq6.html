영웅의 글라디우스 획득 퀘스트 가이드

핵심 요약

  • 영웅의 글라디우스 퀘스트 수행으로 추가 데미지 2,000만 획득
  • 선행 퀘스트 완료가 필수입니다.

1. 선행 퀘스트

필요 재료: 물컹물컹한 액체 50개 / 나뭇잎 50개 / 옥토퍼스의 다리 20개

  1. 헤네시스 마야와 대화 (마야의 집)
  2. 리스항구 태오에게 이동
  3. 페리온 소피아와 대화 후 만지에게서 '아르고의 피' 1개 획득
  4. 소피아에게 재료 전달 후 '반짝이는 돌' 제작
  5. 리스항구 태오에게 반짝이는 돌 전달
  6. 헤네시스 마야에게 돌아가 선행 퀘스트 완료

2. 영웅의 글라디우스 진행

  1. 페리온 만지와 대화 후 퀘스트 수락
  2. 슬리피우드 크리슈라마와 대화
  3. 재료 수집:
    • 별의 돌: 엘리니아 아르웬
    • 얼음 조각: 아르웬에게 '아르웬의 유리구두' 전달 후 획득 (확률 50%)
    • 고대의 주문서: 다크스톤골렘 사냥
    • 불꽃 깃털: 레드 드레이크 사냥
  4. 크리슈라마에게 재료 전달 후 '각성된 글라디우스' 획득
  5. 만지에게 돌아가 완료 후 '영웅의 글라디우스' 선택

Tip. 아르웬의 유리구두 수급

해외유령선 1 → 마을귀환서 → 좌측 포탈 → 하단 포탈(중심 도로 3) → 속도제한 표지판 사냥 (0.5% 확률 드롭)
