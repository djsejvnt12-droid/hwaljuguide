도깨비 방망이 획득 퀘스트 가이드

핵심 요약

  • 아랫마을 박첨지 연계 퀘스트
  • 완료 보상: 추가 데미지 2,000만 획득

필수 준비물

  • 절구공이 5개 (월묘) / 호랑이 발도장 4개 (호돌이)
  • 삼미호의 꼬리 3개 (삼미호) / 새우살 20개 (아쿠아리움 크립)

선행 퀘스트

  1. 칠성과 칠남의 '의좋은 두 형제' 진행
  2. 칠성: 절구공이 5개 + 1,000메소 → 돼지고기 산적 획득
  3. 칠남: 호랑이 발도장 4개 + 1,000메소 → 메밀묵 획득
  4. 콩쥐 연계 퀘스트: 삼미호의 꼬리 3개 + 1,000메소 → 곡차 획득

도깨비 방망이 진행

  1. 아랫마을 박첨지와 대화 후 재료(산적, 메밀묵, 곡차) 확인
  2. '도깨비 퇴치' 수락 후 까막산 깊은 산 흉가로 이동
  3. 지정된 위치에 재료를 떨어뜨려 왕도깨비 3마리 소환 후 처치
  4. 퀘스트 아이템(감투, 방망이, 망토) 획득
  5. 박첨지에게 돌아가 보상으로 '도깨비 방망이' 선택
